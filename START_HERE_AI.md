# AI Assisted One Run Portfolio Setup

This path is for a coding agent with filesystem and terminal access, not a chat window that cannot
operate on a repository.

1. Use this repository as a GitHub template or clone it.
2. Copy `starter-input/profile.example.json` to `starter-input/profile.json` and fill it in.
3. Add reviewed photos and project media, plus optional UI/brand references.
4. Paste [`prompts/ONE_RUN_PORTFOLIO.md`](prompts/ONE_RUN_PORTFOLIO.md) into Codex, ChatGPT with a
   coding workspace, Claude Code, Gemini CLI, GitHub Copilot coding agent, or another capable agent.
5. Review the agent's local preview and evidence.
6. Approve account login, domain, DNS, or deployment only when you are ready.

The default result is a verified static Astro site deployable to Cloudflare Pages. Sanity remains
optional. No agent should place a token in source control or claim deployment success without
checking the live URL.

See [`docs/AI_ONE_RUN_SETUP.md`](docs/AI_ONE_RUN_SETUP.md) for the complete contract and
[`docs/HOSTING_AND_UPGRADE_PATHS.md`](docs/HOSTING_AND_UPGRADE_PATHS.md) for optional paid paths.
