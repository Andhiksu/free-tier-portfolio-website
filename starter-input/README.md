# Starter input

Put only material you own and intend to publish here. The coding agent treats this folder as input,
not as automatic publication approval.

- Edit `profile.example.json` and save it as `profile.json`.
- Put a profile image in `assets/profile/`.
- Put selected project media in `assets/projects/`.
- Put public-safe certificates in `assets/credentials/` only when you have reviewed every detail.
- Put screenshots, links, or sketches that describe the desired look in `ui-references/`.
- Put logos, colors, and typography references in `brand-references/`.

Never add passwords, API tokens, `.env` files, private identity documents, private client material,
or unredacted certificates. The agent must ask before account login, purchases, DNS changes, or
deployment.
